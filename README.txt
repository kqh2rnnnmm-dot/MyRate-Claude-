ОДНО ЗАМЕЧАНИЕ ПО НОВОЙ ИКОНКЕ
Тёмная форма в новом дизайне почти касается краёв квадрата 1024×1024
(отступы по краям — примерно 12–14%, а не привычные 20%+ для
«маскируемых» adaptive-иконок Android). Сейчас в manifest.webmanifest
иконки 192 и 512 px помечены как "purpose": "any maskable" — это
значит, что Android при желании может обрезать иконку по кругу или
скруглённому квадрату, и в таком случае часть тёмной формы обрежется
по краям. На iPhone (apple-touch-icon) эта проблема не возникает —
там углы просто скругляются системой, форма внутри не обрезается.
Это не баг встраивания, а особенность геометрии самого утверждённого
рисунка. Если увидишь обрезанные края на Android — можно либо
попросить отредактировать SVG с отступом под safe zone, либо убрать
пометку "maskable" из манифеста (тогда Android покажет иконку целиком,
но без адаптивной формы).

УСТАНОВКА
1. Распакуй архив MyRate_3_1_3_5.zip.
2. Открой репозиторий my-rate на GitHub.
3. Нажми Add file → Upload files.
4. Загрузи в корень репозитория файлы приложения из архива:
   index.html, styles.css, config.js, storage.js, calculator.js,
   collections.js, interface.js, app.js, manifest.webmanifest,
   myrate-icon.svg, apple-touch-icon.png, icon-192.png,
   icon-512.png и icon-1024.png.
5. Нажми Commit changes и дождись обновления GitHub Pages.
6. Открой MyRate по прежнему адресу и обнови страницу.

ZIP, README, CHECKS и папку verification в GitHub загружать не нужно.
Старые файлы заранее не удаляй, данные сайта не очищай и приложение не удаляй.

ПРОВЕРКА НА IPHONE
1. Обнови страницу в браузере — вкладка/фавикон должны показывать
   новую иконку.
2. Если MyRate уже добавлен на домашний экран как приложение —
   иконка на домашнем экране сама не обновится, её нужно удалить
   и добавить заново через «Поделиться» → «На экран Домой», чтобы
   увидеть новую версию.
3. Приложение открывается и работает как раньше — профиль,
   Избранное, Большие планы и Архив на месте.
