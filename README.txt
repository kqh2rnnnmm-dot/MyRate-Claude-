MYRATE — ОБНОВЛЕНИЕ 3.2.0 (ПОДАЧА И ЭМОЦИЯ: ХОЛОДНАЯ ТОЧНОСТЬ)

ЧТО ИЗМЕНИЛОСЬ

1. ЧЕСТНАЯ СТАВКА — БЕЗ НОВЫХ ВОПРОСОВ
Профиль по-прежнему спрашивает только сумму, период, рабочие дни и
часы. Налог, отпуск и дорога добавлены как допущения по умолчанию
(НДФЛ 13%, отпуск 28 дней, дорога 0 часов) — они молча участвуют в
расчёте. Кому нужна точность, открывает свёрнутый блок «Как считается»
в профиле и правит три поля. Новых личных данных приложение не просит
и никуда не отправляет: всё остаётся на устройстве.

Формула:
  чистый доход в месяц = доход × (1 − налог)
  рабочих дней в месяц = (дни в неделю × 52 − отпуск) / 12
  часов в месяц       = рабочие дни × (часы в день + дорога)
  ставка              = чистый доход / часы в месяц

Старые сохранённые профили подхватывают допущения по умолчанию при
загрузке — формат данных на устройстве не сломан.

2. ВТОРОЙ ЦЕННИК КАК ПОСТОЯННЫЙ ЭЛЕМЕНТ
Карточка результата (в текущем расчёте, в «Избранном» и в «Больших
планах») теперь показывает три уровня:
  — общая цена мелко сверху, как факт из внешнего мира;
  — личная цифра крупно в центре — сколько это стоит в твоём времени;
  — эквиваленты (рабочие дни, месяцы) и строка допущений, из которых
    собрана ставка.

3. ВИТРИНА
Монохромная поверхность, одна акцентная краска — только для личной
цифры. Прямые углы вместо крупных скруглений, тонкие линии вместо
теней, табличные цифры (разряды не прыгают при пересчёте), больше
пустоты.

4. ОДНО ДВИЖЕНИЕ ВМЕСТО «МАГИИ»
Искусственная пауза с прыгающими точками убрана. Оверлей ожидания
остался только там, где ожидание настоящее — при запросе курса валют.
Локальный пересчёт мгновенный: цифра не появляется, а встаёт на место.
Настройка переименована в «Движение цифр» и по-прежнему отключается,
как и при системном «уменьшить движение».

5. ТОН
Шутливые реплики заменены короткими констатациями. Тумблер «Шутки и
реплики» остался, но теперь переключает два честных регистра: с
характером и предельно сухой.

ЧТО НЕ МЕНЯЛОСЬ
— Философские слайды «Второй ценник» по содержанию — только оформление.
— Экраны, навигация, поиск, Архив, конвертация валют, PWA-иконки.
— Формат данных, сохранённых на устройстве пользователя.

УСТАНОВКА
1. Распакуй архив MyRate_3_2_0.zip.
2. Открой репозиторий my-rate на GitHub.
3. Нажми Add file → Upload files.
4. Загрузи в корень репозитория файлы приложения из архива:
   index.html, styles.css, config.js, storage.js, calculator.js,
   collections.js, interface.js, app.js, manifest.webmanifest,
   myrate-icon.svg, icon-192.png, icon-512.png, icon-1024.png,
   apple-touch-icon.png.
5. Commit changes.
6. На iPhone открой сайт и обнови страницу; при установленном на
   экран «Домой» приложении удали и добавь заново, чтобы подхватилась
   новая версия.
