MYRATE — ИСПРАВЛЕНИЕ 3.1.3.7 (ФРАЗА В ШАПКЕ И «РАССЛОЕНИЕ» ЭКРАНА)

ЧТО БЫЛО НЕ ТАК В 3.1.3.6
По скриншотам нашлась настоящая причина: способ, которым сжималась
фраза «ВРЕМЯ — деньги...», был реализован неправильно технически —
я одновременно и уменьшал текст, и обрезал его по жёстко заданной
высоте в пикселях. Обрезка срабатывала раньше уменьшения, поэтому:
— в развёрнутом виде текст обрезался посередине буквы, хотя скролла
  ещё не было;
— в свёрнутом виде вторая половина фразы пропадала совсем вместо
  того чтобы уменьшиться;
— из-за той же неточности в подсчёте высоты нижний край шапки не
  совпадал с тем, что реально показывалось на экране — отсюда и
  «расслоение», рваный стык между шапкой и заголовком экрана под ней.

ЧТО ИСПРАВЛЕНО
Переделан сам механизм сжатия. Теперь фраза уменьшается только одним
способом — визуальным масштабированием, без обрезки по высоте. Место,
которое высвобождается при уменьшении, «забирается» обратно через
корректную разметку, а не через отдельно посчитанную и потому иногда
неточную высоту в пикселях. Из-за этого:
— текст никогда не обрезается посередине буквы — ни в развёрнутом,
  ни в промежуточном состоянии при прокрутке;
— высота шапки всегда точно совпадает с тем, что реально на экране,
  без рваных стыков.
Логика — липкая шестерёнка и плавное сжатие всей фразы до высоты
иконки — осталась прежней, поменялась только техника реализации.

УСТАНОВКА
1. Распакуй архив MyRate_3_1_3_7.zip.
2. Открой репозиторий my-rate на GitHub.
3. Нажми Add file → Upload files.
4. Загрузи в корень репозитория файлы приложения из архива:
   index.html, styles.css, config.js, storage.js, calculator.js,
   collections.js, interface.js, app.js, manifest.webmanifest,
   myrate-icon.svg, apple-touch-icon.png, icon-192.png,
   icon-512.png и icon-1024.png.
5. Нажми Commit changes и дождись обновления GitHub Pages.
6. Открой MyRate по прежнему адресу и обнови страницу.

ZIP, README, CHECKS и папку verification в GitHub загружать не нужно.
Старые файлы заранее не удаляй, данные сайта не очищай и приложение не удаляй.

ЧТО ПРОВЕРИТЬ НА IPHONE
1. Открой экран «Хочу — могу?» без прокрутки — фраза «ВРЕМЯ — деньги.
   Какую цену платишь именно ТЫ?» должна быть видна целиком, без
   обрезанных букв, и заголовок «Ценник умеет притворяться» под ней —
   без рваного стыка с шапкой.
2. Медленно прокрути вниз — вся фраза должна плавно и целиком
   уменьшаться (а не обрезаться и не исчезать частично), пока не
   станет примерно как шестерёнка по высоте.
3. Прокрути обратно наверх — фраза должна плавно вернуться к полному
   размеру, снова без обрезки.
4. Ещё раз обрати внимание на стык между шапкой и содержимым экрана
   во время прокрутки — не должно быть рваного/двойного слоя.
Автотесты этого не проверяют (jsdom не считает реальную раскладку
страницы), так что здесь важна именно проверка на самом телефоне.
